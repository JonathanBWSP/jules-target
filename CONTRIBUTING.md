# Contributing Guidelines

Thank you for contributing to `tinyq`!

## Pull request conventions

Every pull request description must end with a tracking line of the form:

```
Tracking: http://149.248.4.51:8080/p/15-03/<branch-name>
```

where `<branch-name>` is the PR's head branch (e.g. `Tracking: http://149.248.4.51:8080/p/15-03/my-feature-branch`). Reviewers use the dashboard behind that link to track pull requests.
